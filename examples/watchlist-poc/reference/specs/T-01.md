# T-01: Rating scale + notch calculator (REQ-06-02)

## User story
As a credit analyst, I want to pick a previous and a current rating and see the notch change and its WL, so that I don't count notches by hand.

## Traces to
AC-1, AC-2 · REQ-06-02 · clarifications C1–C3

## Acceptance criteria
1. Given the scale of C1, when `RATING_SCALE` is read, then it has 19 entries, `AAA` first and `CCC-` last.
2. Given "BBB+" and "BB+", when `notchChange` runs, then it returns 3 (downgrade is positive).
3. Given "BB+" and "BBB+", when `notchChange` runs, then it returns -3.
4. Given " bbb+ " and "BB+", when `notchChange` runs, then it returns 3 (trimmed, case-insensitive).
5. Given an unknown rating ("ZZZ" or ""), when `notchChange` runs, then it throws `RangeError`.
6. Given "BBB+" and "BB+", when `notchCalculator` runs, then it returns `{ notches: 3, direction: "downgrade", wl: 2 }`.
7. Given "BBB+" and "BBB-", when `notchCalculator` runs, then `wl` is 1; given "BBB+" and "BBB", then `wl` is 0.
8. Given an upgrade or an unchanged rating, when `notchCalculator` runs, then `wl` is 0 and `direction` is "upgrade" / "unchanged".

## Edge cases
- Extremes: "AAA" → "CCC-" = 18.
- Non-string input (undefined, null) → RangeError.
