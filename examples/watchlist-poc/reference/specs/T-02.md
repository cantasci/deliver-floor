# T-02: Indicator 12 — country rating change → WL (REQ-03-12)

## User story
As a credit analyst, I want the country rating change turned into a WL automatically, so that Indicator 12 is consistent.

## Traces to
AC-3 · REQ-03-12 · clarification C3

## Acceptance criteria
1. Given "BB" → "BB-" (1 notch down), when `countryRatingChangeWl` runs, then it returns 1.
2. Given "BB" → "B+" (2 notches down), when it runs, then it returns 2; "BBB" → "B" (5 down) → 2.
3. Given an upgrade ("BB-" → "BB") or no change ("AAA" → "AAA"), when it runs, then it returns 0.
4. Given an unknown rating, when it runs, then the `RangeError` from `notchChange` propagates.

## Edge cases
- Built on `notchChange` from `src/ratings/notch.mjs` — no second rating scale.
