## Acceptance criteria
1. (AC-5) Given a 1-notch country downgrade, when `countryRatingChangeWl("A","A-")` is called, then it returns `1`. This differs on purpose from `notchCalculator`'s `wl: 0` for the same move (C6).
2. (AC-5) Given a 2-notch downgrade, when `countryRatingChangeWl("A","BBB+")` is called, then it returns `2`.
3. (AC-5) Given a 3-notch downgrade, when `countryRatingChangeWl("A","BBB")` is called, then it returns `2`.
4. (AC-5) Given the largest downgrade (18 notches), when `countryRatingChangeWl("AAA","CCC-")` is called, then it returns `2`.
5. (AC-6) Given an upgrade, when `countryRatingChangeWl("A-","A")` or `countryRatingChangeWl("CCC-","AAA")` is called, then it returns `0`.
6. (AC-6) Given an unchanged rating, when `countryRatingChangeWl("BB","BB")` is called, then it returns `0`.
7. (AC-5, AC-6) Given any pair `(p, c)` of the 19×19 C1 scale (`RATING_SCALE` × `RATING_SCALE`, 361 pairs), when `countryRatingChangeWl(p, c)` is called, then `typeof result === "number"`, the result is in {0, 1, 2} and it equals `n >= 2 ? 2 : n === 1 ? 1 : 0`, where `n = notchChange(p, c)`.
8. (AC-7) Given `countryRatingChangeWl(" a ","a-")`, when called, then it returns `1`.
9. (AC-7) Given `countryRatingChangeWl(" bbb\n","BB+")`, when called, then it returns `2`. Under the C1 order BBB → BBB- → BB+ is 2 notches. This is the corrected value; any test asserting another value is wrong.
10. (AC-7) Given `countryRatingChangeWl("aaa","ccc-")`, when called, then it returns `2`.
11. (AC-7) Given NBSP or tab padding in the current position, when `countryRatingChangeWl("A"," a-\t")` is called, then it returns `1`.
12. (AC-8) Given an invalid string in either position (`""`, `"   "`, `"BBB +"`, `"B B B"`, `"BB++"`, `"AAA-"`, `"D"`, `"NR"`, `"Baa1"`, `"ＢＢＢ"`), when `countryRatingChangeWl(x,"BBB")` or `countryRatingChangeWl("BBB",x)` is called, then a `RangeError` is thrown and nothing is returned.
13. (AC-8) Given a non-string primitive in either position (`null`, `undefined`, `3`, `NaN`, `true`, `10n`, `Symbol("BBB")`), when `countryRatingChangeWl` is called with it, then a `RangeError` is thrown. It must never be a `TypeError`.
14. (AC-8) Given an object in either position (`{}`, `Object.create(null)`, `["BBB"]`, `{ toString: () => "BBB" }`, `new String("BBB")`), when `countryRatingChangeWl` is called with it, then a `RangeError` is thrown.
15. (AC-8) Given a missing argument, when `countryRatingChangeWl("BBB")` or `countryRatingChangeWl()` is called, then a `RangeError` is thrown.
16. (AC-8) Given an invalid argument, when `countryRatingChangeWl` throws, then the error is the one `notchChange` raised, passed through unchanged. It is not caught, not wrapped, and there is no fallback `0`.
17. (AC-9) Given `src/indicators/countryRating.mjs`, when its source is read, then it contains `import { notchChange } from "../ratings/notch.mjs"` (either quote style).
18. (AC-9) Given the same source, when it is read, then it holds no rating codes (no match for `/["'](AAA|AA[+-]?|A[+-]|BBB[+-]?|BB[+-]?|B[+-]|CCC[+-]?)["']/`) and no index table of its own.
19. (AC-9) Given `await import("../../src/indicators/countryRating.mjs")`, when its keys are read, then `Object.keys(module)` deep-equals `["countryRatingChangeWl"]`.

## Edge cases
- Notch boundaries: 0 → 0, 1 → 1, 2 → 2, 3 and above → 2, any negative (−1 to −18) → 0. Unchanged gives `0`, never `-0` or any other falsy value.
- Both scale ends work in both positions (`AAA`, `CCC-`).
- No third parameter. An edited auto-filled value is passed as `current` (C7). An extra third argument is ignored.
- Whitespace inside a rating (`"BBB +"`, `"B B B"`) and full-width characters (`"ＢＢＢ"`) are rejected. The only normalisation is `trim()` plus case-folding (X-trim).
- `new String("BBB")` and `{ toString: () => "BBB" }` are rejected, never coerced (CON-errors).
- Building the error message must not throw for `Symbol` or `Object.create(null)`. That is `notchChange`'s job (T-01, merged), and this card proves it by the RangeError type.
- The file does no I/O: no `node:` imports, no `process.`, no `console.`, no `eval`, no `Function(`, no dynamic `import(` (NFR-security, CLAUDE.md).
- `src/ratings/notch.mjs` is not changed by this card.
