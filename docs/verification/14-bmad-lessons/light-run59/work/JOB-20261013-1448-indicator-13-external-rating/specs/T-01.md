# T-01: Indicator 13: externalRatingChangeWl(previous, current) on notchChange

## User story
As a credit-monitoring analyst, I want the Watchlist level for a change in a client's external rating calculated automatically, so that a client downgraded by 2 or more notches is flagged as WL 1 or WL 2 in the same way every time.

## Traces to
AC-1, AC-2, AC-3, AC-4, AC-5, AC-6. REQ-03-13. Readiness CON-interface, CON-errors, CON-compat and X-rating-scale.

## Acceptance criteria
1. (AC-1, REQ-03-13) Given previous `"BBB+"` and current `"BBB-"` (+2 notches), when `externalRatingChangeWl("BBB+", "BBB-")` is called, then it returns exactly the number `1` (`assert.strictEqual(..., 1)`); likewise `("A", "BBB+")` returns `1`.
2. (AC-2, REQ-03-13) Given a downgrade of 3 or more notches, when `externalRatingChangeWl` is called, then it returns `2`: `("BBB+", "BB+")`, `("BBB+", "BB")`, `("AAA", "CCC-")`.
3. (AC-3, REQ-03-13) Given a 1-notch downgrade, no change or an upgrade, when `externalRatingChangeWl` is called, then it returns `0`: `("BBB", "BBB-")`, `("A", "A")`, `("BBB", "BBB+")`, `("BB+", "BBB+")`, `("CCC-", "AAA")`.
4. (AC-4, REQ-03-13) Given ratings with surrounding whitespace or mixed case, when `externalRatingChangeWl` is called, then they are read as `notchChange` reads them: `(" bbb+ ", "bb+")` → `2`, `("bbb+", "Bbb-")` → `1`, `("\tA\n", "a")` → `0`.
5. (AC-5, REQ-03-13) Given a `previous` or `current` that is not one of the 19 grades of `RATING_SCALE` after trim and upper-casing, when `externalRatingChangeWl` is called, then it throws a `RangeError` with the `notchChange` message `unknown rating: <JSON.stringify(input)>` and returns no value; `("BBB+", "nope")` throws `/unknown rating: "nope"/`, `("nope", "BBB+")` throws a `RangeError`.
6. (AC-6, CON-compat) Given the change is applied, when `node --test` runs, then every existing test passes unchanged, no existing file under `src/` or `test/` is modified, and the module's only import is `notchChange` from `../ratings/notch.mjs`.

## Edge cases
- Exactly +2 notches → `1`; exactly +3 → `2`; +18 (AAA→CCC-) → `2`.
- Exactly +1 notch → `0` (where Indicator 12 thresholds would wrongly give 1); 0 and −1 → `0`; −18 → `0`. No negative WL.
- Argument order matters: `("BBB-", "BBB+")` → `0`, `("BBB+", "BBB-")` → `1`.
- Off-scale `"D"`, `"SD"`, `"CC"`, `"C"`, `"NR"`, `"WD"`, `"Baa1"` throw `RangeError` (accepted risk X-rating-scale).
- `""`, `"   "`, `null`, `undefined` throw `RangeError` in either position; inner whitespace `"BBB +"` throws.
- The return value is always a `number`.
