# T-01: isInvestmentGrade(rating) in src/ratings/notch.mjs

## User story
As a credit-monitoring developer using the Watchlist rating module, I want `isInvestmentGrade(rating)` to tell me whether a rating is investment grade, so that I don't have to compare `RATING_SCALE` indices by hand.

## Traces to
AC-1, AC-2, AC-3, AC-4, AC-5. Readiness CON-interface, CON-errors, CON-compat, PRD-conflicts (a), NFR-security.

## Acceptance criteria
1. (AC-1) Given `import { isInvestmentGrade } from "src/ratings/notch.mjs"`, when called with each of the 19 canonical ratings, then it returns `true` for `AAA, AA+, AA, AA-, A+, A, A-, BBB+, BBB, BBB-` and `false` for `BB+, BB, BB-, B+, B, B-, CCC+, CCC, CCC-`. Every result satisfies `typeof result === "boolean"`.
2. (AC-2) Given the boundary, when called, then `isInvestmentGrade("BBB-") === true` and `isInvestmentGrade("BB+") === false`.
3. (AC-3) Given padded or other-case input, when called, then `isInvestmentGrade(" bbb- ") === true`, `isInvestmentGrade("bb+") === false`, `isInvestmentGrade("\tAaA\n") === true` and `isInvestmentGrade("ccc-") === false`. Normalisation goes through the module's private `indexOf`, not a second copy of the logic.
4. (AC-4, NFR-security) Given input that does not normalise to a scale entry, when called, then it throws a `RangeError` whose `message` is exactly `` `unknown rating: ${JSON.stringify(input)}` ``. It never returns `false` for such input.
5. (AC-5) Given the module after the change, then `Object.keys(notch).sort()` deep-equals `["RATING_SCALE", "isInvestmentGrade", "notchCalculator", "notchChange"]`; `RATING_SCALE.length === 19` and is frozen; `notchChange("BBB+", "BB+") === 3`; `notchCalculator("BBB+", "BB+")` deep-equals `{ notches: 3, direction: "downgrade", wl: 2 }`; `npm test` is green after QA updates line 17 of `test/integration/ratings/notch.int.test.mjs` (the only edit to an existing test).

## Edge cases
- Boundary: `BBB-` true, `BB+` false; ends `AAA` true, `CCC-` false.
- `""`, `"   "`, `null`, `undefined`, no argument → RangeError (not false).
- Off-scale codes `"D"`, `"SD"`, `"NR"`, `"WD"` → RangeError.
- Inner whitespace (`"BBB -"`) and suffixes (`"BBB-u"`) → RangeError.
- `5` → RangeError `unknown rating: 5`. `String()`-coercible inputs (`["AAA"]`) are accepted as `notchChange` accepts them; parity, no test needed.
