# T-02: Indicator 12 country rating change WL (src/indicators/countryRating.mjs)

## User story
As a credit-risk analyst using the Watchlist POC, I want Indicator 12 to turn a country's previous and current rating into WL 0, 1 or 2, so a client in a downgraded country is flagged on the right level.

## Traces to
AC-8, AC-9 in full. AC-4, AC-5 for `countryRatingChangeWl`. AC-10 Indicator 12 part and "built on notchChange" review. AC-11 countryRating.mjs part and full suite.

## Acceptance criteria
Each criterion reads: Given the inputs named, when the function is called, then the result or error is as stated.
1. (AC-8) `countryRatingChangeWl(previous,current)` returns primitive number 1 for exactly 1 notch downgrade and 2 for 2+: ("BBB+","BBB")→1, ("CCC","CCC-")→1, ("BBB+","BBB-")→2, ("BBB+","BB+")→2, ("AAA","CCC-")→2.
2. (AC-8, C6) For ("BBB+","BBB") countryRatingChangeWl gives 1 while notchCalculator(...).wl gives 0.
3. (AC-9) Upgrade or unchanged → 0 with Object.is(r,0): ("BBB","BBB+"), ("BB+","BBB+"), ("CCC-","AAA"), ("BBB","BBB"), ("aa"," AA ") all → 0.
4. (AC-4) Case/trim() whitespace tolerated in either position: (" bbb+ ","BBB")→1, ("bbb+","\tbbb-\n")→2, (" aaa","ccc-　")→2, ("aa"," AA ")→0.
5. (AC-5) Any value not on the scale after trim+upper-case, as previous (current="BBB") or current (previous="BBB") → RangeError, never TypeError (same value list as T-01 incl. Symbol("BBB"), Object.create(null), null, undefined, numbers, objects, arrays, new String("BBB+"), "​BBB", "BBB +", "D", "").
6. (AC-5, X-error-message) countryRatingChangeWl("X","Y") → RangeError whose message contains "previous" and "X": the notchChange error passed through unchanged (no try/catch, no re-wrapping).
7. (AC-10) All 361 pairs: result === (n>=2?2 : n===1?1 : 0) with n = notchChange(p,c); Object.is(result,0) whenever n<=0.
8. (AC-10, review) countryRating.mjs imports notchChange from "../ratings/notch.mjs"; no rating literal ("AAA","BBB+","CCC-"…); no own validation; no threshold helper shared with notchCalculator.
9. (AC-11) typeof countryRatingChangeWl === "function"; calls write nothing to stdout/stderr; package.json unchanged vs main; the only import is ../ratings/notch.mjs; no `console.`, no module-level let/var; the diff touches only src/indicators/** and test/indicators/**; `node --test` (full suite) passes.

## Edge cases
- n=1→1, 2→2, 3→2, 18→2; n=0,-1,-2,-18→0. Scale ends ("CCC","CCC-")→1, ("CCC-","CCC")→0, ("AAA","AA+")→1, ("AA+","AAA")→0.
- Result is +0 for upgrades/unchanged (Math.max(0,n) must not yield -0); always a primitive number.
- Do not touch arguments before calling notchChange. countryRatingChangeWl() and ("BBB") → RangeError.
