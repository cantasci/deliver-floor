# T-02 (re-plan of T-01): Notch calculator: RATING_SCALE and notchChange in src/ratings/notch.mjs

## User story
As the author of Indicators 11, 12 and 13, I want to import `notchChange(previous, current)` and `RATING_SCALE` from `src/ratings/notch.mjs`, so that I get the signed number of notches between two ratings (downgrade positive, upgrade negative) and a clear RangeError on bad input.

## Traces to
AC-1 … AC-14; REQ-06-02 (part); clarifications C1 (scale, trim, case), C2 (RangeError), C3 (sign), C4 (no I/O); readiness ARC-stack, ARC-layer. PM decision: `RATING_SCALE` is frozen.

## Acceptance criteria
Index on `RATING_SCALE` (0-based): AAA 0, AA+ 1, AA 2, AA- 3, A+ 4, A 5, A- 6, BBB+ 7, BBB 8, BBB- 9, BB+ 10, BB 11, BB- 12, B+ 13, B 14, B- 15, CCC+ 16, CCC 17, CCC- 18. Public names: `RATING_SCALE`, `notchChange` (named exports of `src/ratings/notch.mjs`, and no others).

1. AC-1: Given the module is imported, when `RATING_SCALE` is read, then it is exactly the 19 strings AAA, AA+, AA, AA-, A+, A, A-, BBB+, BBB, BBB-, BB+, BB, BB-, B+, B, B-, CCC+, CCC, CCC- in that order; `length === 19`, `[0] === 'AAA'`, `[18] === 'CCC-'`, and `Object.isFrozen(RATING_SCALE)` is true.
2. AC-2: Given `'BBB+'` then `'BB+'`, when `notchChange('BBB+','BB+')`, then `3`.
3. AC-3: Given `'BB+'` then `'BBB+'`, when `notchChange('BB+','BBB+')`, then `-3`.
4. AC-4: Given `'A'` and `'A'`, when `notchChange('A','A')`, then `0` and `Object.is(result, 0)` is true (not `-0`).
5. AC-5: Given any two scale ratings p, c, when `notchChange(p,c)`, then the result is an integer equal to index(c) − index(p); `notchChange(p,c) === -notchChange(c,p)`. Examples: `('A-','BBB+')` → 1; `('AA-','A+')` → 1; `('AAA','CCC-')` → 18; `('CCC-','AAA')` → -18; `('B-','CCC+')` → 1.
6. AC-6: Given all 19×19 = 361 pairs of `RATING_SCALE`, when `notchChange(p,c)` is called, then each result equals index(c) − index(p) and `Number.isInteger` is true.
7. AC-7: Given surrounding whitespace removable by `String.prototype.trim()`, when called, then it is ignored: `notchChange('  BBB+ ','BB+')` → 3; `notchChange('A\t','\nA')` → 0.
8. AC-8: Given lower or mixed case, when called, then it is treated as upper case: `('bbb+','bb+')` → 3; `('Bb+','bbb+')` → -3; `('ccc-','aaa')` → -18.
9. AC-9: Given an unknown rating string in either argument, when called, then `RangeError` is thrown: `'XYZ'`, `'D'`, `'BBB +'`, `'A++'`, `'AAA+'`, `'B+-'` (each tried as previous and as current, with a valid other argument such as `'A'`).
10. AC-10: Given `''` or `'   '` in either argument, when called, then `RangeError` is thrown.
11. AC-11: Given a non-string in either argument, when called, then `RangeError` (never `TypeError`) is thrown for each of: `undefined`, `null`, `5`, `true`, `{}`, `['A']`, `Symbol('A')`, `new String('A')`; and `notchChange()` with no arguments throws `RangeError`.
12. AC-12: Given one valid and one invalid argument (either order) or both invalid (`('nope','nope')`), when called, then `RangeError` is thrown and no number is returned.
13. AC-13: Given valid and invalid calls, when run, then nothing is written to `process.stdout` or `process.stderr` (stubbed `.write` not called), importing the module has no side effects, the module exports exactly `RATING_SCALE` and `notchChange`, and `package.json` is unchanged (no dependencies).
14. AC-14: Given the card is done, when `node --test test/ratings/notch.test.mjs` and `node --test` run, then both exit 0 with tests covering AC-1 … AC-12 passing.

## Edge cases
- Type check comes first: `typeof x === 'string'` before any trim/upper-case, so `Symbol('A')` yields `RangeError`, not `TypeError`, and `new String('A')` is rejected.
- Each argument is validated independently; both are validated before returning (an invalid `previous` with a valid `current`, and the reverse, both throw).
- `'  '` (whitespace-only) and `''` trim to empty → `RangeError`.
- No inner-space removal, no Unicode folding, ASCII `-` only: `'BBB +'`, `'A++'`, `'AAA+'`, `'B+-'` are invalid. `'AA+'` is valid (index 1) while `'AAA+'` is not.
- Equal ratings, even with different case/whitespace (`' a '`, `'A'`), give `0` (never `-0`).
- Extremes: `('AAA','CCC-')` → 18, `('CCC-','AAA')` → -18.
- Error message text is free; tests assert only `instanceof RangeError`.
