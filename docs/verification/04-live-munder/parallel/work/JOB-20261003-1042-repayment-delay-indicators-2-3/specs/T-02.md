# T-02 — REQ-03-03 Indicator 3 "Delays in 12 months": `DELAY_COUNT_OPTIONS` + `delayCountWl`

## User story
As a developer building the Watchlist POC screens (EPIC-03), I want a pure function that turns the Indicator 3 "Delays in 12 months" dropdown option into a Watchlist level (WL), plus the ordered option list, so the screens can render the exact allowed labels and obtain the WL without re-implementing the rule.

## Edge cases
- Numbers vs strings: `delayCountWl(1)` → RangeError while `delayCountWl("1")` → `1`; `delayCountWl(0)` → RangeError while `delayCountWl("0")` → `0`. Must not use `String(option)`, `Number(option)` or `==`.
- No numeric parsing: `"01"`, `"1.0"`, `"-1"`, `"2"`, `">2"` → RangeError.
- Inner whitespace not normalised: `"> 1"` → RangeError.
- Look-alike characters: `"≥1"` (U+2265) → RangeError.
- Lookup-table trap: `"constructor"`, `"__proto__"`, `"toString"` must throw, not return an inherited property; no plain `{…}` lookup.
- Message-building trap: `Symbol("1")`, `Object.create(null)`, `1n` must still end in `RangeError`.
- Empty after trimming: `""`, `"   "` → RangeError.
- Characters outside `String.prototype.trim()` (zero-width space `"​1"`) → RangeError.
- The list cannot grow: after a failed `push("2")`, `"2"` is still unknown → RangeError.
