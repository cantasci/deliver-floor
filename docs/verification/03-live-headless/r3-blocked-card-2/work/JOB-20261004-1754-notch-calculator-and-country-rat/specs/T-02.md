# T-02: Indicator 12 country rating change WL: countryRatingChangeWl (src/indicators/countryRating.mjs)

## Edge cases
- Boundaries: n=0 → 0, n=1 → 1, n=2 → 2, n=18 → 2. Negative n → 0 whatever its size ((CCC-,AAA) → 0; a Math.abs bug is caught by criterion 4).
- ("BBB-","BB+") → 1 (calculator gives wl 0 for the same pair).
- Ind. 12 and calculator disagree at n=1 (1 vs 0) and n=2 (2 vs 1); elsewhere they agree, e.g. ("A+","A-") → Ind. 12 gives 2, calculator wl 1.
- Both invalid → error names `previous`. Missing argument: `countryRatingChangeWl("BBB")` → RangeError naming `current`.
- `["BBB"]` and `new String("BBB")` throw RangeError (inherited from notchChange; if it fails raise as Open issue against T-01, do not patch here).
- Return value is a plain number, never undefined/NaN/-0.
- "SD"/"RD" throw RangeError — recorded risk, not a defect.
