# T-02: Indicator 12 country rating change WL (REQ-03-12)

## User story
As a credit analyst, I want to enter a counterparty country's previous and current rating and get the Indicator 12 Watchlist level (0, 1 or 2), so that a country downgrade raises the client's WL as REQ-03-12 requires.

## What to build
- `src/indicators/countryRating.mjs` exports only `countryRatingChangeWl(previous, current)` -> `0 | 1 | 2`: `n = notchChange(previous, current)`; `n ≤ 0` -> 0 (C3); `n === 1` -> 1; `n ≥ 2` -> 2.
- The only import is `import { notchChange } from '../ratings/notch.mjs';`. Trimming, case-folding and `RangeError` all come from `notchChange`; nothing duplicated, caught or wrapped.
- Exactly two parameters: no defaults, no override argument, no module state.
- Unit tests in `test/indicators/countryRating.test.mjs`. Do not edit `src/ratings/notch.mjs`; report T-01 defects instead.

## Edge cases
- Boundaries: notchChange −1 and 0 -> 0; 1 -> 1; 2 -> 2. Scale ends: (AAA,CCC-) -> 2, (CCC-,AAA) -> 0.
- No "unchanged" special case: an equal pair after normalisation, e.g. `("aaa","AAA ")`, returns 0.
- Any invalid argument throws `RangeError` straight from `notchChange`; no try/catch, no conversion, no re-validation. Missing argument = `undefined` = throws.
- The C6 divergence is intended: do not harmonise and do not reuse `notchCalculator(...).wl`.
- Extra arguments ignored (no override, C7). Same input always gives the same output.
