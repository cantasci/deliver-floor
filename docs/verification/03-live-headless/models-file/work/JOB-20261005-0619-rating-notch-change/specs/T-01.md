# T-01: ratings-lib: add `src/ratings/notch.mjs` with a frozen `RATING_SCALE` and `notchChange(previous, current)`, plus TDD unit tests

## What to build
- **New file `src/ratings/notch.mjs`** (plain Node 18+ ESM, no `import` statements, no I/O, no console output). Exactly two named exports, no default export:
  - `export const RATING_SCALE = Object.freeze(['AAA','AA+','AA','AA-','A+','A','A-','BBB+','BBB','BBB-','BB+','BB','BB-','B+','B','B-','CCC+','CCC','CCC-'])`. Best first, index 0..18.
  - `export function notchChange(previous, current)`. Synchronous; returns `idx(current) - idx(previous)`, an integer −18..+18. Downgrade positive, upgrade negative, unchanged `0`.
- **Each argument is normalised in this order:**
  1. If `typeof arg !== 'string'`, throw `RangeError` (before `.trim()`).
  2. `s = arg.trim()` (only `String.prototype.trim()`; inner whitespace stays).
  3. `key = s.toUpperCase()` (not `toLocaleUpperCase`).
  4. `idx = RATING_SCALE.indexOf(key)`; `-1` → throw `RangeError`.
- Validate both arguments before computing. Compute `idxCurrent - idxPrevious` directly; never negate, so the result is never `-0`.
- **New file `test/ratings/notch.test.mjs`**: TDD unit tests (`node:test`, `node:assert/strict`), importing from `'../../src/ratings/notch.mjs'`.
- **QA (not the dev)** writes black-box tests in `test/integration/ratings/*.test.mjs` through the public import `'../../../src/ratings/notch.mjs'`.

2. **AC-2** (REQ-06-02, C3): when `notchChange('BB+','BBB+')` is called, then it returns `-3`.
3. **AC-3** (REQ-06-02, C3): for any `r` in `RATING_SCALE` (e.g. `'A'`, `'AAA'`, `'CCC-'`), `notchChange(r, r)` satisfies `Object.is(result, 0)` (not `-0`); `notchChange('A','A')` is `0`.
4. **AC-4** (C1): `RATING_SCALE.length === 19`, it deep-equals `['AAA','AA+','AA','AA-','A+','A','A-','BBB+','BBB','BBB-','BB+','BB','BB-','B+','B','B-','CCC+','CCC','CCC-']`, `[0] === 'AAA'`, `[18] === 'CCC-'`.
5. **AC-5** (X-scale-immutability): `Object.isFrozen(RATING_SCALE) === true`; `RATING_SCALE.push('D')` and `RATING_SCALE[0] = 'X'` each throw `TypeError` in a `.mjs` file; afterwards `length === 19`, `[0] === 'AAA'` and `notchChange('BBB+','BB+') === 3`.
6. **AC-6** (C1, C3): for every `i` in 0..17 `notchChange(RATING_SCALE[i], RATING_SCALE[i+1]) === 1` and reversed `=== -1`; spot checks `('AAA','AA+')=1`, `('BBB','BBB-')=1`, `('BBB-','BBB')=-1`, `('BBB-','BB+')=1`, `('B-','CCC+')=1`; extremes `('AAA','CCC-')=18`, `('CCC-','AAA')=-18`; full 19×19 matrix `notchChange(RATING_SCALE[i], RATING_SCALE[j]) === j - i` (361 pairs).
7. **AC-7** (C1, X-whitespace): `('  BBB+ ','BB+')=3`; `('\tA-\n','A-')=0`; `(' AAA','AA+﻿')=1`; `('BB+',' BBB+\r\n')=-3`.
8. **AC-8** (C1): `('bbb+','bb+')=3`; `('Bb+','bBb+')=-3`; `('aaa','CCC-')=18`; `(' ccc- ','aAa')=-18`; `('a','A')=0`.
9. **AC-9** (C2): each of `'D'`, `'CC'`, `'C'`, `'SD'`, `'NR'`, `'WD'`, `'AAA+'`, `'CCC--'`, `'BBB +'`, `'BBB+.'`, `'A−'`, `'Baa1'`, as `previous` (current `'A'`) and as `current` (previous `'A'`), throws `RangeError` (24 calls).
10. **AC-10** (C2): each of `''`, `'   '`, `'\t\n'`, `' '` in either position (other `'A'`) throws `RangeError` (8 calls).
11. **AC-11** (C2): each of `undefined`, `null`, `3`, `NaN`, `true`, `{}`, `['A']`, `Symbol('A')`, `new String('A')`, `{ toString: () => 'A' }` in either position (other `'A'`) throws `RangeError`, never `TypeError` (20 calls); `notchChange()` and `notchChange('A')` each throw `RangeError`.
12. **AC-12** (C4, ARC-stack): `r = notchChange('BBB+','BB+')` has `typeof r === 'number'` and `typeof r?.then === 'undefined'`; calling twice gives the same value; with `console.log`, `console.error`, `process.stdout.write`, `process.stderr.write` stubbed they are called 0 times across valid and throwing calls; the source of `src/ratings/notch.mjs` matches no `/^\s*import\b/m`; `package.json` has no `dependencies` or `devDependencies` key.
13. **AC-13** (DEL-ci): `node --test` at the repo root exits 0 with 0 failures and the output includes tests from `test/ratings/notch.test.mjs` and `test/integration/ratings/`.

## Edge cases
- Type check comes before `.trim()`: `null`/`undefined` give `RangeError` (not `Cannot read properties of null`), `Symbol('A')` gives `RangeError`.
- `new String('A')` and `{ toString: () => 'A' }` are rejected; no coercion.
- Only leading/trailing whitespace is removed (`\t \n \r`, U+00A0, U+FEFF); `'BBB +'`, `'B B'` are unknown. Whitespace-only trims to `''` → `RangeError`.
- Look-alikes (`'A−'`, full-width letters) do not match → `RangeError`.
- `CC`, `C`, `D`, `SD`, `NR`, `WD` are unknown → `RangeError`; no fallback value.
- Both arguments invalid (`notchChange('D', null)`) → `RangeError`; which one is reported is not contractual. Message text is free; tests use `assert.throws(fn, RangeError)`.
- `assert.equal(-0, 0)` passes under strict mode, so use `Object.is` for AC-3.
- Writes to the frozen `RATING_SCALE` throw only because `.mjs` is strict mode.
- Extra arguments (`notchChange('A','A','B')`) are not specified and not asserted.
