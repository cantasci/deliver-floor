# T-02: Indicator 12 country rating change WL (src/indicators/countryRating.mjs)

## User story
As a credit-monitoring analyst, I want the country (sovereign) rating change turned into a Watchlist level of 0, 1 or 2 automatically, so Indicator 12 is filled the same way every time (REQ-03-12).

## Traces to
AC-5 (country), AC-6 (country), AC-8 (country), AC-11..AC-14, AC-15 (country), AC-16 (country). REQ-03-12; C3, C6, C7; X-wl-thresholds, X-input-trim, X-scale-bounds, X-module-exports. Depends on T-01 (`notchChange`).

## Acceptance criteria
Each criterion reads: Given the inputs listed, When the named function is called (or the module is imported/inspected), Then the stated result holds.
Files: `src/indicators/countryRating.mjs`, `test/indicators/countryRating.test.mjs`. `n = notchChange(previous, current)` from `../ratings/notch.mjs`.

1. AC-5 (country): `countryRatingChangeWl("  a ","a-")` → 1.
2. AC-6 (country): each invalid value from list B, as `previous` (current "BBB") and as `current` (previous "BBB"), throws `instanceof RangeError` — never TypeError, never a value. It is the RangeError from `notchChange`, passed on unchanged (not caught, wrapped or re-validated).
3. AC-8 (country): `countryRatingChangeWl("BBB+","BBB")` → 1 while `notchCalculator("BBB+","BBB").wl` → 0, asserted in one test (the difference is intended).
4. AC-11: ("BBB+","BBB") → 1, ("CCC","CCC-") → 1, ("BBB+","BBB-") → 2, ("BBB+","BB+") → 2, ("AAA","CCC-") → 2.
5. AC-12: ("BBB","BBB+") → 0, ("CCC-","AAA") → 0, ("A","A") → 0.
6. AC-13: for all 361 ordered pairs the result === (n<=0 → 0, n===1 → 1, n>=2 → 2) and is always an integer 0, 1 or 2.
7. AC-14: previous "BBB+": unedited current "BBB" → 1; edited "BB+" → 2; `countryRatingChangeWl.length === 2`; calling ("BBB+","BBB") again after the edited call still gives 1 (no state).
8. AC-15 (country): `Object.keys` of the module is ["countryRatingChangeWl"]; no default export; result is not a Promise.
9. AC-16 (country): `node --test` exits 0; package.json has no dependencies/devDependencies; the only import in countryRating.mjs is `../ratings/notch.mjs` (not notchCalculator); no I/O or console; no file under `src/ratings/**` modified.

## Edge cases
- No own validation or second scale; missing arguments (`countryRatingChangeWl("BBB")`, `()`) throw RangeError.
- Exactly two parameters: no defaults, no rest.
- Boundaries: n = 0 → 0, 1 → 1, 2 → 2, 18 → 2, -1 and -18 → 0.
- A cut below CCC- ("CC", "SD", "D") throws RangeError, does not return 2 (accepted POC limitation).
- Do not reuse `notchCalculator().wl`: thresholds differ (n=1 gives 0 there; n=2 gives 1 there and 2 here).
- Whitespace/look-alike rules inherited from `notchChange`.
