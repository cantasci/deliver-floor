- (constraint) From CLAUDE.md: Node 18+ .mjs ESM, no npm deps, node:test in test/<area>/<name>.test.mjs, pure functions with no I/O in src/ratings and src/indicators (B-10)
- (decision) Paradigm: functional core, library-style, two layers: src/ratings (scale, notch difference) <- src/indicators (WL rules). Prevents WL logic in the scale layer and duplicate scales.
- (decision) Single source of truth: one frozen scale table in src/ratings; WL thresholds as frozen data keyed by kind in src/indicators; no other module hardcodes symbols or thresholds.
- (decision) Result envelope: {ok:true,notches,direction,wl} | {ok:false,error,field}; never throws for bad input; codes unknown_rating|missing_input|unknown_kind.
- (decision) Signed notches: positive = downgrade (B-8); WL from d=max(notches,0) with kind-specific thresholds (B-2, B-3).
- (decision) Consumer contract: one entry point notchCalculator({previous,current,kind}) from src/indicators/notch-calculator.mjs; src/ratings exports ratingPosition and notchChange. Country indicator = kind country, no separate entry.
- (decision) No UI, CLI, I/O, agency awareness, database, integrations or deployment (B-5, B-12). Consumed by import only.
- (assumption) JavaScript ESM is fixed by CLAUDE.md and package.json (type module), not a default; no TypeScript.
- (assumption) Normalization (trim, case-insensitive, Moody's mapping per B-6) lives only in src/ratings.
- (assumption) null/undefined/non-string/blank rating or kind -> missing_input; non-blank string off the scale (incl. NR, WR, SD, D) -> unknown_rating; kind not in the three -> unknown_kind. First failure reported, order previous, current, kind.
- (question) Error precedence and single-error reporting are assumed; confirm if consumers need all errors at once.
- (version) Node v22.11.0 local; CLAUDE.md requires 18+. No external technology named, so no web check needed.
